# 틈 — 서비스 기획서

## 문제와 대상

바쁜 학생과 직장인은 지치거나 집중이 흐트러져도 긴 휴식을 내기 어렵다. 여러 방법을 검색할 여유가 없는 순간에, 지금 상태와 남은 시간에 맞는 짧고 실행 가능한 행동을 바로 제안한다. 의료 상담이나 치료가 필요한 상황은 서비스 범위 밖이다.

## 화면 구성

| 구획 | 목적 | 주요 동작 |
| --- | --- | --- |
| 히어로 | 서비스 가치 전달 | ‘내 루틴 만들기’로 이동 |
| 소개 | 사용 과정 설명 | 기분 → 시간 → 결과 순서 확인 |
| 루틴 만들기 | 입력 및 AI 결과 | 기분·시간 선택, 상황 입력, 생성·재시도 |
| FAQ | 데이터 처리·서비스 범위 안내 | 질문 펼치기 |

상단 메뉴는 각 구획으로 이동한다. 모바일과 데스크톱에서 세로·그리드 레이아웃을 조정하며 키보드로 입력과 결과를 사용할 수 있게 한다.

## 핵심 기능과 AI 흐름

1. 사용자는 기분 `지침/불안/산만/무기력` 중 하나와 시간 `3/5/10/15분` 중 하나를 선택한다. 상황 설명은 160자 이내로 선택 입력한다.
2. 브라우저는 필수 입력을 검사한 뒤 `POST /api/routine`으로 JSON `{mood, minutes, context}`를 전송한다. 로딩 상태와 25초 제한을 표시한다.
3. Python Vercel Function은 입력값을 다시 검사하고 서버 환경 변수 `OPENAI_API_KEY`의 Copa virtual key로 `https://copa.codyssey.kr/v1/chat/completions`를 호출한다. `MODEL` 환경 변수로 모델을 선택한다. 모델은 JSON으로 제목, 소개, 2~3개 단계, 마무리 문장을 돌려준다. 각 단계의 시간 합은 선택한 시간과 같아야 한다.
4. 브라우저는 응답을 안전하게 텍스트로 표시하고 다시 만들기 동작을 제공한다. 개인 입력과 결과를 사이트 데이터베이스에 저장하지 않는다. 사용자가 선택하면 AI 결과 1개만 현재 브라우저의 `localStorage`에 저장한다.

## 보너스 기능

| 항목 | 구현 | 확인 방법 |
| --- | --- | --- |
| 데이터 저장 고도화 | AI 결과를 받은 뒤 **이 기기에 저장**을 눌러 최근 결과 1개를 `localStorage`에 보관한다. 자유 입력 원문·API 키는 별도로 저장하지 않으며, 새로고침 후 **다시 보기**와 **삭제**가 가능하다. 생성 결과에 입력 내용이 반영될 수 있다. 서버나 다른 기기로 동기화되지 않는다. | 생성 → 저장 → 새로고침 → 다시 보기 → 삭제 순서로 확인 |
| UX 고도화 | 밝은 화면과 어두운 화면을 버튼으로 전환하고 선택을 이 브라우저에 기억한다. | 데스크톱 1280px·모바일 375px에서 전환·새로고침·가로 넘침 확인 |

다크 모드의 개선 효과는 두 테마에서 동일한 입력·결과 보기 과제를 수행하게 하고, 완료 여부와 읽기 편안함에 대한 짧은 응답을 비교해 확인한다. 방문자 행동은 추적하지 않는다.

## 응답 지연 개선

현재 `gpt-5-mini`를 기본 경량 모델로 사용하며 자유 입력을 160자로 제한하고, 결과를 2~3개의 한 문장짜리 실행 단계로 요약한다. 향후 자유 입력이 없는 동일한 기분·시간·모델·프롬프트 버전 요청에만 10분 TTL의 서버 측 공유 캐시를 적용할 수 있다(현재 미구현). 자유 입력은 캐시하지 않는다. 응답 시간 중앙값·p95와 캐시 적중률을 측정해 필요하면 더 작은 지원 모델을 선택하거나 소개·마무리 길이를 줄인다.

## 오류 처리

| 상황 | 사용자 안내 |
| --- | --- |
| 기분 또는 시간 미선택 | 두 필수 항목을 선택해 달라고 안내 |
| 잘못된 JSON 또는 허용되지 않은 값 | 입력을 확인해 달라고 안내 |
| AI 서비스 오류·과부하·키 미설정 | 재시도 또는 관리자 문의 안내 |
| 네트워크 단절·시간 초과 | 연결 확인 후 재시도 안내 |
| 예상과 다른 AI 결과 | 처리 실패 안내, 결과는 화면에 표시하지 않음 |

API 키는 코드와 문서에 넣지 않고 Vercel 환경 변수로 관리한다. 일상 루틴 제안은 의료·심리 상담을 대신하지 않음을 결과 화면에 명시한다.

## 검증 시나리오

- 빈 입력에서 API 호출 없이 안내가 나오는지 확인한다.
- 정상 입력에서 2~3개 단계와 정확한 시간 합을 가진 결과가 보이는지 확인한다.
- 긴 입력, 잘못된 JSON, 허용되지 않은 기분·시간이 서버에서 거부되는지 확인한다.
- AI 과부하·연결 오류·시간 초과 시 알맞은 메시지가 나오는지 확인한다.
- 모바일 375px과 데스크톱 1280px에서 메뉴, 폼, 결과가 겹치지 않는지 확인한다.
- 실제 Vercel 배포 후 메뉴 이동과 AI 생성 요청을 운영 URL에서 재확인한다.
- 결과 저장·새로고침·다시 보기·삭제와 다크 모드 선택 유지 여부를 실제 브라우저에서 확인한다.
